BUG FIX SUMMARY
================================================================================

PROBLEM:
  KB-scoped retrieval returns ZERO documents even when files exist
  - Users select a Knowledge Base → zero results
  - Query with generic ("all KBs") → results appear correctly
  - Blocks all KB-based workflows

ROOT CAUSES (TWO COMPOUNDING BUGS):

  Bug 1: Missing document_name in vector payload
    - Location: app/services/ingestion_service.py line ~95
    - Issue: Computed doc_title never passed to vector storage
    - Result: Vectors stored document_name as f"doc_{uuid}" instead of filename
  
  Bug 2: KB post-filter checked wrong field
    - Location: app/retrieval/hybrid.py line ~68
    - Issue: Looked for "title" field (doesn't exist) → fell back to document_id (UUID)
    - Issue: Could never match allowed_file_names (real filenames)
    - Result: All KB-filtered results silently removed

SOLUTION:
  1. Pass document_name to vector storage (fixes root cause)
  2. Implement two-tier filtering with upload_id primary (unambiguous, fast)
  3. Fallback to improved filename lookup for legacy vectors
  4. Provide reindex script to fix existing vectors

VERIFICATION:
  ✅ Regression tests created and passing
  ✅ Backward compatibility verified
  ✅ No breaking API changes
  ✅ No database schema changes required
