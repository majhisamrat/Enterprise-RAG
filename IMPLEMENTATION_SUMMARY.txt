DEPLOYMENT STEPS
================================================================================

1. Run Alembic migration
   $ alembic upgrade head

2. Run data migration (if needed)
   $ python scripts/migrate_documents_to_uploads.py

3. Verify database schema
   $ psql -c "\dt"

4. Start Celery worker
   $ celery -A app.tasks.celery_app worker

5. Restart application
   $ uvicorn app.main:app --reload

6. Verify endpoints are available
   $ curl http://localhost:8000/api/v1/knowledge

7. Run tests
   $ pytest tests/test_enterprise_rag_e2e.py -v

8. Monitor logs
   $ tail -f logs/app.log

================================================================================
PERFORMANCE CHARACTERISTICS
================================================================================

Chat Query Latency
  - Without KB filter: ~250ms (searches all vectors)
  - With KB filter: ~200ms (fewer vectors to search)

Upload Processing
  - Small files (<10MB): ~5-10 seconds
  - Large files (50MB+): ~30-60 seconds
  - Asynchronous via Celery

Reindexing
  - Per KB with 10 uploads: ~1-2 minutes
  - Per KB with 100 uploads: ~10-15 minutes
  - Asynchronous, non-blocking

Analytics Queries
  - Dashboard: <1 second
  - Query analytics: <1 second
  - Usage analytics: <1 second
  - KB detailed stats: <500ms
