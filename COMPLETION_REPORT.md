### ✅ 4. Think Tag Removal
**Issue:** `<think>` tags appearing in responses despite instructions  
**Solution:** Post-processing strips thinking tags before returning answer

**File:** `app/orchestrator/rag.py` (lines 504-509)
```python
# Strip any <think> tags that might appear in output
answer_text = llm_resp.answer
if "<think>" in answer_text or "</think>" in answer_text:
    answer_text = answer_text.replace("<think>", "").replace("</think>", "").strip()
```

## System Architecture

```
User Query
    ↓
[1] Retrieve Documents
    ├─ DuckDB (Structured CSV/Excel)
    ├─ Qdrant Vector Store (Semantic PDF)
    └─ Hybrid Retrieval (Reranking)
    ↓
[2] Build Prompt
    └─ System prompt + Context + Conversation history
    ↓
[3] Generate Response
    ├─ Try Groq: llama-3.2-90b → llama-3.1-70b → llama-3.1-8b
    ├─ Fallback to Gemini: gemini-1.5-pro → gemini-1.5-flash → gemini-2.0-flash
    └─ Final fallback message if all fail
    ↓
[4] Post-Processing
    ├─ Strip <think> tags
    ├─ Format 2-10 lines for structured data
    └─ Clean whitespace
    ↓
Final Answer (2-10 lines, no thinking tags)
```
